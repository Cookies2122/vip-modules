# VIP_Jumps

Дополнительные прыжки в воздухе.

Автор: [Pisex](https://github.com/Pisex) и [ABKAM](https://github.com/ABKAM2023). Оригинал: [Pisex/cs2-vip-modules](https://github.com/Pisex/cs2-vip-modules/tree/main/VIP_Jumps). Перенос на новый SDK и Metamod 2.0: \_ded\_cookies.

## Что нужно

- [Metamod:Source](https://github.com/alliedmodders/metamod-source) 2.0 (KHook)
- [VIP Core](https://github.com/Pisex/cs2-vip)
- [Utils](https://github.com/Pisex/cs2-menus)

## groups.ini

```
"jumps"  "1"
```

| Ключ | Что значит |
| --- | --- |
| `jumps` | сколько дополнительных прыжков |

## vip.phrases.txt

Допишите внутрь блока `"Phrases"`:

```
"jumps"
{
	"en"		"Jumps"
	"ru"		"Прыжки"
}
```
